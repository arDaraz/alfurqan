# Phase 01.1 — UI Design Contract

> Visual and interaction contract for QCF Mushaf Page Renderer. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native / Expo -- shadcn not applicable) |
| Preset | not applicable |
| Component library | React Native core (View, Text, Pressable, StyleSheet) |

This phase renders Quran text inside `react-native-webview`. The Mushaf page styling is defined as HTML/CSS (not React Native StyleSheet). The design contract below specifies both the native shell and the WebView HTML/CSS values.

### WebView HTML/CSS (Mushaf Page Content)

QCF fonts are glyph fonts -- each character is a pre-rendered calligraphic glyph. Typography settings control spacing and alignment, not letterform rendering.

| Property | Value | Rationale |
|----------|-------|-----------|
| font-family | `'QCF_P{pageNumber}'` | Page-specific QCF v2 font |
| font-size | `28px` | Readable glyph size for mobile screens |
| line-height | `1.9` | Vertical spacing between the 15 Mushaf lines to fill page height |
| direction | `rtl` | Arabic text direction |
| text-align | `justify` | Full-width justified lines matching printed Mushaf |
| font-display | `block` | Prevent flash of unstyled text while font loads |
| letter-spacing | `0` | QCF glyphs have built-in spacing |
| word-spacing | `-2px` | Tighten default browser word spacing for QCF glyph sequences |

## Layout Contract

### MushafReader (Container)

```
+--------------------------------------------------+
|  [Back]     Surah Name (Arabic)     [Page X/604] |  <-- Navigation header
+--------------------------------------------------+
|                                                  |
|              +----------------------+            |
|              |                      |            |
|              |   MushafPage         |            |
|              |   (WebView)          |            |
|              |   15 lines of QCF    |            |
|              |   justified text     |            |
|              |                      |            |
|              +----------------------+            |
|                                                  |
+--------------------------------------------------+
|              Page 123 / 604                      |  <-- PageIndicator
+--------------------------------------------------+
```

- **PagerView**: Full screen width, horizontal scroll, RTL orientation
- **offscreenPageLimit**: 1 (3 pages mounted: current, previous, next)
- **Page transition**: Native swipe gesture via `react-native-pager-view`
- **Swipe direction**: Left = next page (higher number), Right = previous page (lower number) -- RTL book convention

### MushafPage (Single Page)

- **WebView**: `scrollEnabled={false}`, `javaScriptEnabled={false}`
- **HTML structure**: Single `<div class="page">` containing 15 `<div class="line">` elements
- **Each line**: Contains QCF `code_v2` characters as `innerHTML`, rendered with page-specific `@font-face`
- **Centered lines**: Surah headers use `text-align: center` instead of `justify` (controlled by `is_centered` logic: lines containing only surah-name or basmallah glyphs)

### PageIndicator

- Position: Bottom of screen, above safe area
- Background: `#FFFFFF` (surface)
- Height: 44px (touch-target minimum)
- Content: `{current_page}` in accent gold (`#C9A84C`, weight 700, 18px) + ` / 604` in secondary text (`#6B7280`, weight 400, 14px)
- Alignment: Centered horizontally

## WebView HTML Template Contract

The `mushafHtml.ts` utility generates a complete HTML document. Exact structure:

```html
<!DOCTYPE html>
<html dir="rtl" lang="ar">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no">
  <style>
    @font-face {
      font-family: 'QCF_P{PAGE}';
      src: url(data:font/woff2;base64,{BASE64_FONT_DATA});
      font-display: block;
    }
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body {
      background-color: #FAF8F2;
      color: #1A1A2E;
      font-family: 'QCF_P{PAGE}';
      font-size: 28px;
      line-height: 1.9;
      direction: rtl;
      display: flex;
      flex-direction: column;
      justify-content: center;
      min-height: 100vh;
      padding: 16px;
      -webkit-user-select: none;
      user-select: none;
      overflow: hidden;
    }
    .line {
      text-align: justify;
      width: 100%;
    }
    .line-centered {
      text-align: center;
      width: 100%;
    }
  </style>
</head>
<body>
  <!-- 15 lines generated here -->
  <div class="line">{code_v2 characters for line 1}</div>
  <div class="line">{code_v2 characters for line 2}</div>
  ...
  <div class="line-centered">{surah header line if applicable}</div>
  ...
</body>
</html>
```

### CSS Constraints

- `user-scalable=no`: Prevent pinch-to-zoom (conflicts with PagerView swipe)
- `-webkit-user-select: none`: Prevent text selection (no interaction in this phase)
- `overflow: hidden`: No scrolling inside WebView
- `min-height: 100vh` + `justify-content: center`: Vertically center the 15 lines
- `display: flex; flex-direction: column`: Stack lines vertically

## State Specifications

### Loading State

**When**: First page data (words + font) is being fetched from SQLite.

- Use existing `LoadingSkeleton` component (3 groups of shimmer blocks)
- Same visual as current reader loading state
- Duration: Typically <100ms (local SQLite read)

### Error State

**When**: SQLite query fails for page data or font data.

- Use existing `ErrorState` component
- Error message: See Copywriting Contract below
- Retry action: Re-fetch current page data

### Empty State

**Not applicable** for this phase. Mushaf always has 604 pages -- there is no "empty" condition. If a page has no words in the database, that indicates a seeding error (treated as error state, not empty state).

### Page Transition State

**When**: User swipes to a new page and the WebView is rendering.

- **No intermediate loading indicator**: The `offscreenPageLimit={1}` pre-loads adjacent pages. The user sees the rendered page immediately.
- **If adjacent page not yet ready**: Show blank page with `#FAF8F2` background (matches overall background -- no visual flash). The WebView will render within 1-2 frames.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Reduced motion | Inherited from `LoadingSkeleton` -- respects `AccessibilityInfo.isReduceMotionEnabled()` |

| Text scaling | QCF glyphs are fixed-size by design (calligraphic glyphs, not scalable text) -- document this limitation |

## Performance Contract

| Metric | Target | Mechanism |
|--------|--------|-----------|
| Page render time | <200ms | Pre-loaded via `offscreenPageLimit={1}`, base64 font inlined |
| Memory: mounted WebViews | 3 max | PagerView mounts current +/- 1 page only |
| Memory: cached page data | 10 pages max | `useMushafPage` hook LRU cache |
| Font data per page | ~20KB base64 | WOFF2 compression, single font per page |
| Total DB size increase | ~17MB | Words table (~8MB) + fonts table (~9MB) |
